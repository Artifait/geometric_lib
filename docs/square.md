# Модуль square.py (Квадрат)

Предназначен для расчетов квадрата.

## Функции

### 1. `area(a)`
Вычисляет площадь квадрата по длине его стороны.
* **Аргументы:** `a` (float/int) — сторона квадрата.
* **Возвращает:** (float/int) — площадь.

**Пример вызова:**
```python
import square

print(square.area(4))  # Выведет 16
```

### 2. `perimeter(a)`
Вычисляет периметр квадрата.
* **Аргументы:** `a` (float/int) — сторона квадрата.
* **Возвращает:** (float/int) — периметр.

**Пример вызова:**
```python
import square

print(square.perimeter(4))  # Выведет 16
```

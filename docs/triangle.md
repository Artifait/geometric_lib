# Модуль triangle.py (Треугольник)

Предназначен для геометрических расчетов треугольника.

## Функции

### 1. `area(base, height)`
Вычисляет площадь треугольника по основанию и проведенной к нему высоте.
* **Аргументы:** 
  * `base` (float/int) — длина основания.
  * `height` (float/int) — высота треугольника.
* **Возвращает:** (float) — площадь.

**Пример вызова:**
```python
import triangle

print(triangle.area(6, 4))  # Выведет 12.0
```

### 2. `perimeter(a, b, c)`
Вычисляет периметр треугольника по трем сторонам.
* **Аргументы:** `a`, `b`, `c` (float/int) — длины трех сторон треугольника.
* **Возвращает:** (float/int) — периметр.

**Пример вызова:**
```python
import triangle

print(triangle.perimeter(3, 4, 5))  # Выведет 12
```

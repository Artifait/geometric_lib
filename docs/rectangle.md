# Модуль rectangle.py (Прямоугольник)

Предназначен для геометрических расчетов прямоугольника.

## Функции

### 1. `area(a, b)`
Вычисляет площадь прямоугольника по двум смежным сторонам.
* **Аргументы:** `a`, `b` (float/int) — стороны прямоугольника.
* **Возвращает:** (float/int) — площадь.

**Пример вызова:**
```python
import rectangle

print(rectangle.area(10, 5))  # Выведет 50
```

### 2. `perimeter(a, b)`
Вычисляет периметр прямоугольника.
* **Аргументы:** `a`, `b` (float/int) — стороны прямоугольника.
* **Возвращает:** (float/int) — периметр.

**Пример вызова:**
```python
import rectangle

print(rectangle.perimeter(10, 5))  # Выведет 30
```

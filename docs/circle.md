# Модуль circle.py (Круг)

Предназначен для работы с окружностями.

## Функции

### 1. `area(r)`
Вычисляет площадь круга по его радиусу.
* **Аргументы:** `r` (float/int) — радиус круга.
* **Возвращает:** (float) — площадь круга.

**Пример вызова:**
```python
import circle

res = circle.area(5)
print(res)  # Выведет примерно 78.5398...
```

### 2. `perimeter(r)`
Вычисляет периметр (длину окружности) по её радиусу.
* **Аргументы:** `r` (float/int) — радиус круга.
* **Возвращает:** (float) — длина окружности.

**Пример вызова:**
```python
import circle

res = circle.perimeter(5)
print(res)  # Выведет примерно 31.4159...
```
